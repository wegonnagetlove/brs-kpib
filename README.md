# БРС 104 КПИБ

Сайт-калькулятор баллов БРС группы 104 КПИБ (ВШГА МГУ).

## Файлы

- `index.html`: весь сайт, одна страница. Данные берёт из Google-таблицы «БРС-для-сайта».
- `apps-script/Code.gs`: код Apps Script (проект «баллы кпиб»): загрузка подтверждений, лист «Заявки», правка заявок с сайта, обновление листа «Расписание» из выгрузки портала.
- `data/raspisanie.xlsx`: исходный лист «Расписание» (импортируется в таблицу один раз).

## Откуда сайт берёт данные

| Лист таблицы | Что на сайте |
|---|---|
| Баллы (Сводка) | баллы и пропуски на карточках |
| ПРОИ, ПВДИ, АПИП, ФилПр | вкладка «По дням» |
| Заявки (если нет, то Мероприятия) | вкладка «Мероприятия», отчёт |
| Расписание | «осталось занятий X из N» |

## Обновление

- Баллы, заявки, расписание: правятся в таблице, сайт подхватывает сам.
- Расписание с портала: файл выгрузки кладётся в папку «Расписание БРС 104 КПИБ» на Google Диске, раз в час скрипт обновляет лист.
- Код сайта: заменить `index.html` здесь и на хостинге.
- Код скрипта: заменить текст в Apps Script, затем «Развертывание» → «Управление развертываниями» → «Новая версия».
